Comprehensive Feature Matrix

Engineered with modular ES2022 architecture, WebAssembly, and low-latency buffer managers for demanding media playback.

Quad-Screen Multi-View

Watch up to 4 live television streams concurrently in a split-screen matrix. Swap audio channels, mute individual viewports, and navigate slots with a single click.

Xtream Codes & M3U Engine

Full authentication support for Xtream Codes API (Live, VOD movies, series, catchup) and M3U/M3U8 playlist URLs or local files with category grouping and account manager.

XMLTV EPG Schedule Grid

Interactive real-time Electronic Program Guide (EPG) schedule matrix displaying broadcast schedules, episode details, active timeline progress, and one-click channel tuning.

WASM Hashing Engine

WebAssembly memory pipeline executing low-level CRC32 checksums, FNV-1a string hashing, and data parsing with immediate JS fallback for ultimate speed and compatibility.

Live Timeshift & DVR Recording

Pause and seek back in live streams using seekable media buffers. Click "Record Stream" to record broadcasts live using Web MediaRecorder directly to disk.

Picture-in-Picture & Auto-PiP

Pop streams out into floating Picture-in-Picture windows. Auto-PiP seamlessly switches video to floating mode when minimizing or switching tabs.

Audio Visualizer & Screen Cast

Real-time Web Audio API frequency spectrum analyzer canvas and native Presentation API / AirPlay integration for casting to Smart TVs.

Parental Lock & Security

SHA-256 PIN-protected parental controls filter sensitive categories and streams with strict HTML escaping for complete security and XSS prevention.

8 Dynamic UI Themes

Personalize your viewing environment with TellyX Crimson Cinema, OLED Pitch Black, Obsidian Cobalt, Cyberpunk Neon, Emerald Synth, Sunset Coral, Gold Luxury, and Nordic Frost.
